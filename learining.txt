Python

ETL / Data ingestion

# Data loading and automation

We used Python for:

- Reading CSV files using Pandas.
- Inspecting and profiling datasets.
- Processing data in chunks (5,000 or 10,000 rows).
- Converting dates and numeric columns.
- Handling missing values as SQL NULL.

## 5. How our ETL process works

For each CSV, we followed this flow:

1. Start ETL log

   Insert a `RUNNING` record into `audit.etl_execution_log`.
2. Read CSV

   Pandas reads the source file in chunks.
3. Process data

   Select columns, convert required datatypes and handle missing values.
4. Load into SQL Server

   `PyODBC` and `executemany()` insert records into the Bronze table.
5. Commit transaction

   Save inserted records.
6. Finish ETL log

   Update row counts, end time and `SUCCESS` status. If an error occurs, record `FAILED` and its error message.

## 6. Interview explanation — practice this

You can explain the work completed so far like this:

I am building an end-to-end SQL Data Warehouse project using the Brazilian E-Commerce dataset by Olist.

I started by downloading and profiling nine CSV files using Python and Pandas. I checked the row counts, columns, missing values, duplicates and datatypes.

Then I created a SQL Server database called `OlistStore_DW` and organized it into Bronze, Silver, Gold and Audit schemas.

For the Bronze layer, I designed nine SQL tables based on the source CSV structures.

I used Python with Pandas and PyODBC to automate the ingestion process. The scripts read CSV files in chunks, handled datatype conversions and NULL values, and inserted the records into SQL Server.

I also implemented an ETL logging framework that records pipeline names, source and target tables, execution timestamps, row counts and success or failure status.

Finally, I verified all nine tables using SQL queries and checked the ETL execution logs. All nine Bronze ingestion pipelines completed successfully, with 1,560,922 total records loaded.

The next phase is to clean and standardize the data in the Silver layer.
