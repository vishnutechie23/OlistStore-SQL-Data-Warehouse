1. PROJECT OVERVIEW
-------------------

Project Name:
Olist Store SQL Data Warehouse

Dataset:
Brazilian E-Commerce Public Dataset by Olist

Database:
OlistStore_DW

Database Platform:
Microsoft SQL Server 2025 Express

Purpose of Bronze Layer:
The Bronze Layer is the initial layer of the data warehouse.
Its primary purpose is to store raw source data from CSV files
in SQL Server tables.

The Bronze Layer acts as the source layer for further data
processing and transformation in the Silver Layer.


2. SOURCE DATASET
-----------------

The project uses the Brazilian E-Commerce Public Dataset
provided by Olist.

The dataset contains information related to:

- Customers
- Orders
- Order Items
- Payments
- Reviews
- Products
- Sellers
- Geolocation
- Product Category Translations

Source files are stored in the project dataset directory.

Dataset Directory:
C:\OlistStore-SQL-Data-Warehouse\dataset

5. DATA INGESTION PROCESS
-------------------------

The source CSV files are loaded into SQL Server under the
Bronze schema.

Main ingestion steps:

1. Source CSV files are stored in the dataset directory.

2. SQL Server database OlistStore_DW is used as the target
   database.

3. Bronze schema is created to organize raw source tables.

4. Raw table structures are created in the Bronze schema.

5. CSV data is loaded into the corresponding Bronze tables
   using SQL Server-side data loading.

6. Loaded records are checked against the source dataset
   using row count comparisons.

Important:
The Bronze Layer focuses on raw data storage.
Business transformations and analytical calculations are
not performed at this stage.


6. RAW DATA HANDLING
--------------------

The Bronze Layer preserves source data for downstream
processing.

The following principles are followed:

- Original source records are retained.
- No business-level transformations are performed.
- Duplicate records are investigated rather than
  automatically removed.
- Missing values are not automatically replaced.
- Source relationships are examined for data understanding.
- Data quality issues are documented for further processing.

The Bronze Layer provides the raw foundation for the
Silver Layer.


7. INITIAL DATA VALIDATION
--------------------------

After loading the source CSV files, initial validation
checks are performed.

The following checks are included:

1. Row Count Validation
   - Compare source dataset record counts with Bronze
     table record counts.
   - Confirm that the expected records are loaded.

2. Duplicate Analysis
   - Investigate duplicate records.
   - Examine business key uniqueness.

3. NULL Value Analysis
   - Identify missing values in source columns.
   - Understand the distribution of NULL values.

4. Key and Relationship Analysis
   - Examine primary business keys.
   - Check relationships between orders, customers,
     products, sellers, payments and reviews.

5. Geolocation Analysis
   - Investigate duplicate ZIP code and location records.
   - Examine ZIP code coverage.

6. Category Translation Analysis
   - Examine category translation coverage.
   - Identify categories without English translations.


8. IMPORTANT DATA QUALITY OBSERVATIONS
--------------------------------------

During initial data investigation:

- Geolocation contains repeated ZIP code and location
  combinations, which require further analysis.

- Some product categories do not have English translations.

- Source data contains missing values in certain columns.

- Source business keys and relationships are examined
  before performing Silver Layer transformations.

These observations are carried forward for appropriate
handling in the Silver Layer.

11. NEXT PROCESSING LAYER
-------------------------

The next stage is the Silver Layer.

The Silver Layer processes Bronze data through:

- Data cleaning
- NULL handling
- Duplicate handling
- Data standardization
- Data type validation
- Data quality checks
- Relationship validation

The processed Silver tables become the source for
Gold Layer dimensional modeling.
